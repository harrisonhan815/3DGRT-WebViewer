# 3DGRT Viewer

基于原生 JavaScript、HTML/CSS 和 WebGL2 的高斯场景查看器。GLSL 在浏览器本地显卡渲染，Web Worker 负责模型解码、校验和深度排序；无需服务端 CUDA 渲染。支持三阶 SH、FP16 SH 压缩模型、针孔显示与鱼眼对比。

## 访问

在线页面：https://harrisonhan815.github.io/3DGRT-WebViewer/

模型通过 HTTPS 从 `models.hhds-us01.xyz` 下载，页面内可选择已配置的模型。需启用浏览器硬件加速，并使用支持 WebGL2 的浏览器。

本地预览：在本目录运行 `python -m http.server 8080 --bind 127.0.0.1`，打开 http://localhost:8080/ 。

## 操作

| 输入 | 功能 |
| --- | --- |
| 鼠标左键拖动 | 转动视角 |
| 鼠标右键或 Shift＋拖动 | 平移 |
| 滚轮、W/S | 前后移动 |
| A/D、Q/E | 左右平移、下降/上升 |
| Shift＋移动键 | 加速移动 |
| 触屏单指拖动 | 转动视角 |
| 触屏双指同时上滑 / 下滑 | 沿校准后的竖直方向升高 / 降低 |
| 右摇杆 | 沿校准后的地平面前后、左右移动，保持高度 |

手机横屏和竖屏均在右下角显示一个小型摇杆。摇杆向上为前进、向下为后退，左右为平移；前进方向是当前视线在校准地平面上的投影，抬头或低头不会改变移动高度。偏移越大速度越快，松手即停。没有左摇杆。

在画面空白区域单指拖动调整朝向，可与摇杆同时使用；双指同时上下滑动只控制高度，左右滑动或捏合不再平移、前进。打开菜单、切换模型、转屏或切后台会清除当前输入，避免持续移动。点左上角菜单可调整移动速度等选项。

默认渲染长边 **960 px**、垂直视场角 **90°**。移动自适应分辨率默认关闭，可手动开启并选择目标帧率；实际速度取决于设备和场景。切换相机、模型或重置视角会恢复默认 FOV。

页面支持相机预设、重置视角、保存图片和可选的同位姿 180° 鱼眼小窗。可视化地平面工具允许拖动三个轴和绕轴旋转；加载时自动读取模型目录的 `alignment.json`，静态页面保存时会下载新的校正文件。

退出前可点击“安全退出”，停止下载与渲染并清理资源。浏览器不允许自动关闭标签页时，在提示清理完成后手动关闭。
