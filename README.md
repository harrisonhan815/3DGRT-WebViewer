# 3DGRT Viewer

基于原生 JavaScript、HTML/CSS 和 WebGL2 的高斯场景查看器。GLSL 在浏览器本地显卡渲染，Web Worker 负责模型解码、校验和深度排序；无需服务端 CUDA 渲染。支持三阶 SH、FP16 SH 压缩模型、SOG v2、针孔显示与鱼眼对比。SOG 使用 PlayCanvas SplatTransform 编码，浏览器通过 jSquash/libwebp WASM 解码。

## 访问

在线页面：https://harrisonhan815.github.io/3DGRT-WebViewer/

在线页面读取 `models.json`，模型通过 HTTPS 从 `models.hhds-us01.xyz` 下载，页面内可选择已配置的模型。需启用浏览器硬件加速，并使用支持 WebGL2 的浏览器。

本地服务：在本目录运行：

```bash
python serve.py
```

默认监听 `0.0.0.0:55505`。本机打开 `http://127.0.0.1:55505/`，远程电脑或手机打开 `http://服务器公网IP:55505/`；公网访问需要该主机的 TCP 55505 端口可达。`0.0.0.0` 是监听地址，浏览器使用主机实际地址。可用 `--bind`、`--port` 修改监听设置；按 Ctrl+C 停止服务。

更新代码后重启服务并刷新页面。代码与模型列表不使用本地服务的浏览器缓存，入口、渲染器和 Worker 使用一致的资源版本；模型二进制文件仍可缓存。若旧标签页仍显示旧版报错，关闭后重新打开或按 Ctrl+F5 强制刷新。

该服务默认读取独立的 `models.local.json`，通过公网 IP 连接此服务也使用这份列表。模型地址写成 `models/模型目录/manifest.json`，从运行服务的主机下载；相对地址以 JSON 所在目录为基准。添加本地模型或修改默认模型时编辑此文件，然后刷新页面。

需要本地服务使用线上列表时运行 `python serve.py --catalog models.json`，也可用页面参数 `?catalog=models.json` 临时切换。普通静态服务默认读取 `models.json`；需要本地列表时使用 `?catalog=models.local.json`。`?model=zj-office1` 可直接选中 office1，`?url=模型manifest地址` 仍可直接打开单个模型。

本地 office1 可用 `?model=zj-office1` 打开。页面提供 **SOG / 二进制** 两个按钮：双版本模型初次只加载 SOG，点击二进制按钮后才下载、解码并切换；下载期间仍可操作当前画面。切换保留相机位置、朝向、FOV 和未保存的地平面校正，两个版本共用相机列表和 `alignment.json`。重新选择模型或刷新页面会从 SOG 开始，上次选择或 URL 中的 `variant=bin` 不会触发二进制自动下载。

页面只缓存已请求的版本；两个版本都加载过后，再次切换复用已下载的数据，显卡仅驻留当前版本。切换模型或安全退出会取消下载、清除缓存；二进制下载失败时，当前 SOG 仍可浏览，点击按钮可重试。旧的单版本模型正常加载其唯一版本，并隐藏版本切换按钮。

SOG 是有损量化，主要减少下载体积，不会自动减少高斯数量或提高渲染帧率。主动加载两个版本后，总下载量和 CPU 内存占用会增加。双版本导出、独立 IMU 校正脚本和发布步骤见 [模型导出与自动校正](docs/SOG.md)。

## 操作

| 输入 | 功能 |
| --- | --- |
| 鼠标左键拖动 | 转动视角 |
| 鼠标右键或 Shift＋拖动 | 平移 |
| 滚轮、W/S | 前后移动 |
| A/D、Q/E | 左右平移、下降/上升 |
| Shift＋移动键 | 加速移动 |
| 触屏单指拖动 | 转动视角 |
| 触屏双指同时上滑 / 下滑 | 沿校准后的竖直方向升高 / 降低 |
| 右摇杆 | 沿校准后的地平面前后、左右移动，保持高度 |

手机横屏和竖屏均在右下角显示一个小型摇杆。摇杆向上为前进、向下为后退，左右为平移；前进方向是当前视线在校准地平面上的投影，抬头或低头不会改变移动高度。偏移越大速度越快，松手即停。没有左摇杆。

在画面空白区域单指拖动调整朝向，可与摇杆同时使用；双指同时上下滑动只控制高度，左右滑动或捏合不再平移、前进。打开菜单、切换模型、转屏或切后台会清除当前输入，避免持续移动。点左上角菜单可调整移动速度等选项。

默认渲染长边 **960 px**、垂直视场角 **90°**。移动自适应分辨率默认关闭，可手动开启并选择目标帧率；实际速度取决于设备和场景。切换相机、模型或重置视角会恢复默认 FOV。

“影石 / 标准 3DGS 兼容模式”选择项已隐藏并保持关闭，模型配置中的旧启用标记不会重新打开它。页面使用径向排序，主画面投影按模型列表配置，鱼眼小窗仍采用鱼眼投影与径向排序。

`zj-office1-insta` 已接入当前双版本格式，可从列表选择“office1-官方版”。其 `org/` 中的原始 SOG、相机和体素文件保留；当前 `model.sog` 保持原始 SOG 字节，不做二次聚类，浏览器解码为 FP32。原有压缩二进制缓存仍可通过按钮加载。它保留全部高斯、三阶 SH 和官方相机列表；体素碰撞数据暂不用于浏览。适配命令见 [模型导出与自动校正](docs/SOG.md)。

右上角“安全退出”下方独立显示主画面的实际完成 FPS，菜单收起时也可见，支持手机横屏和竖屏。静止且未开启持续渲染时显示 `0.0 FPS / 静止`；需要测持续帧率时，可打开“持续渲染 / 测帧率”。左侧详细耗时统计仍保留。

页面支持相机预设、重置视角、保存图片和可选的同位姿 180° 鱼眼小窗。可视化地平面工具允许拖动三个轴和绕轴旋转；加载时自动读取模型目录的 `alignment.json`。通过本机 localhost 地址查看服务目录中的模型时，保存会写回该模型目录；远程浏览、静态页面或 CDN 模型会下载新的校正文件，放回模型目录后生效。

退出前可点击“安全退出”，停止下载与渲染并清理资源。浏览器不允许自动关闭标签页时，在提示清理完成后手动关闭。
